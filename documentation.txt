1. WHAT THIS APP IS
───────────────────────────────────────────────────────────────────────────────
A chat-style AI web application for IIT-JEE **Advanced** preparation, powered by
the Google Gemini API. Unlike a plain chatbot, Gemini acts as the REASONER and
ORCHESTRATOR, while every real computation is executed by local, verified
computation engines (SymPy, NumPy/SciPy, formula solvers, a Manim renderer).
The model plans tool calls; the engines compute; the model writes the final
exam-style solution with the verified numbers. It can also generate labelled
SVG diagrams, interactive 3D scenes, HTML animations, and fully rendered
Manim videos (MP4).

Key properties:
  • Chat window UI (dark theme) with retractable left sidebar storing all
    previous chats (server-side JSON persistence).
  • Text input with: ∑ƒ scientific-notation keypad (LaTeX/Greek/calculus
    templates), attachment button (PDF/DOCX/TXT/CSV/images), and a
    capabilities dropdown (Numerical / Diagram / Animation / Manim Video).
  • Every response has ⧉ Copy (text) and ⬇ Download (media: SVG/HTML/MP4/PNG).
  • KaTeX math rendering, streaming responses (SSE), tool-call chips you can
    expand to see exactly what each engine computed.
  • The Gemini API key is pre-installed (baked into config.py as a fallback
    AND stored in .env) — the app works out of the box.

2. QUICK START
───────────────────────────────────────────────────────────────────────────────
  ./setup.sh      # one-time: apt packages (ffmpeg, LaTeX, Manim libs), pip
                  # packages, KaTeX + three.js download
  ./run.sh        # serve on http://0.0.0.0:8000 (PORT env var to change)

  ~1 GB RAM is enough (Manim renders at 480p15 by default).

  The API key is already installed. To change it: sidebar → Settings (⚙) →
  paste new key → Save (persists to .env), or edit .env directly.

3. THE FOUR CAPABILITY MODES
───────────────────────────────────────────────────────────────────────────────
🧮 NUMERICAL  — Full exam-style solutions:
    📋 Setup (Given/To-find) → 🧠 Concept (+formulae) → ✍️ numbered Solution
    steps → ✅ Final Answer in \boxed{} → ⚡ Pitfalls & Tips.
    Gemini plans calls to the 38-tool engine suite (below); up to 7 tool
    rounds per question; every number is engine-verified. The final write-up
    streams token-by-token.

📐 DIAGRAM   — Returns STRICT JSON from Gemini:
    • kind="svg": a complete standalone, dark-theme SVG diagram (force
      vectors, ray optics, reaction mechanisms, shaded calculus regions,
      hatched grounds, angle arcs, labelled quantities).
    • kind="3d": a scene JSON (spheres/boxes/cylinders/arrows/lines/planes/
      cones/labels) rendered live in the chat with three.js — drag to rotate,
      scroll to zoom, optional auto-rotate (e.g. VSEPR molecules, field
      geometry, crystal structures, rotational mechanics).
    SVGs are saved to media/diagrams/*.svg (downloadable).

🎬 ANIMATION — A single self-contained animated HTML file (no external
    resources): 2D canvas/SVG or 3D WebGL via the bundled three.js +
    SimpleOrbit helper injected server-side. ~8–20 s looping physics with
    play/pause + speed controls. Saved to media/anim/*.html, shown in a
    sandboxed iframe, downloadable.

🎥 MANIM VIDEO — Gemini writes a complete Manim CE scene (MathTex LaTeX
    equations are supported — LaTeX is installed), the server renders a real
    MP4 with ffmpeg. If the render fails, the compile error is sent back to
    the model which fixes the code and re-renders (up to 2 attempts).
    Output: media/manim/<id>.mp4 + the source .py, both downloadable.
    Quality: -ql (480p15, default) / -qm (720p30) / -qh (1080p60) in Settings.

10. SECURITY NOTES
───────────────────────────────────────────────────────────────────────────────
• .env is in .gitignore — the key is NOT committed by normal git workflows.
• The key ALSO ships embedded in config.py (owner's explicit request) so the
  app "just works". If you publish the repo publicly, REGENERATE the key at
  aistudio.google.com first (it was shared in chat), then update .env/Settings;
  optionally blank EMBEDDED_GEMINI_KEY in config.py.
• python_exec sandbox: separate process, banned-token filter (os/sys/subprocess/
  network/open/exec/eval…), 25 s timeout, no workspace write access.
• Manim renderer: banned-import regex list before executing model code.
• Animation iframes are sandboxed (allow-scripts only, no same-origin).

"No Gemini API key"        Settings (⚙) → paste key. (Embedded fallback makes
                           this rare.)
404 model no longer…       Model deprecated for your key — keep the default
                           3.6-flash or pick another from Settings.
503 / "high demand"        Google free-tier load. The app retries across 4
                           models; resend after a minute if all fail.
Manim render fails         ./setup.sh ensures ffmpeg+LaTeX; auto-fix loop
                           handles most code errors (2 attempts).
Slow videos                Use 480p15 quality; 1 GB VMs: render at 480p.
KaTeX/three.js missing     Re-run ./setup.sh (downloads into static/js/).
CORS/host issues           Server binds 0.0.0.0 and serves the SPA itself —
                           access via the same origin only.
