              JEE TUTOR — LOCAL PC TESTING GUIDE (before OCI deploy)
═══════════════════════════════════════════════════════════════════════════════

Your API key is ALREADY INSTALLED (.env + baked into config.py) — the app works
the moment it starts. No key setup needed.

───────────────────────────────────────────────────────────────────────────────
STEP 1 — GET THE APP ONTO YOUR PC
───────────────────────────────────────────────────────────────────────────────
Download jee-tutor.zip (from this chat's workspace) and extract it.
Extract to a SIMPLE path with no spaces, e.g.  C:\jee-tutor  (Windows)
or  ~/jee-tutor  (Linux/Mac). Avoid OneDrive/Desktop sync folders for WSL.

───────────────────────────────────────────────────────────────────────────────
STEP 2 — PICK HOW TO RUN IT (3 options)
───────────────────────────────────────────────────────────────────────────────
OPTION A — WSL2 (RECOMMENDED: 100% of features, same as this sandbox)
───────────────────────────────────────────────────────────────────────────────
  1. PowerShell (as Administrator):   wsl --install -d Ubuntu
     → reboot, create a Ubuntu username/password.
  2. In Ubuntu:
       sudo apt update && sudo apt install -y python3-pip python3-venv
       mkdir ~/apps && cp -r /mnt/c/jee-tutor ~/apps/    # copy OFF /mnt/c (fast I/O)
       cd ~/apps/jee-tutor
       python3 -m venv .venv && source .venv/bin/activate
       pip install -r requirements.txt
       ./setup.sh          # ffmpeg + LaTeX + system libs (needs sudo, ~5-10 min)
       ./run.sh
  3. Open http://localhost:8000 in your Windows browser.

OPTION B — DOCKER DESKTOP (EASIEST if you already have Docker)
───────────────────────────────────────────────────────────────────────────────
  cd C:\jee-tutor
  docker build -t jee-tutor .
  docker run -d -p 8000:8000 --name jee jee-tutor
  → http://localhost:8000   (everything included: Manim + LaTeX)

OPTION C — NATIVE WINDOWS PYTHON (QUICK TEST, ~90% of features)
───────────────────────────────────────────────────────────────────────────────
  1. Install Python 3.11–3.13 from python.org → tick "Add python.exe to PATH".
  2. Command Prompt in C:\jee-tutor:
       python -m venv .venv
       .venv\Scripts\activate
       pip install -r requirements.txt
       python -m uvicorn app:app --host 0.0.0.0 --port 8000
  3. http://localhost:8000
  NOTES for Option C:
   • Numerical / Diagram / Animation modes work FULLY.
   • Manim video: renders fine WITHOUT LaTeX too — the app auto-detects that
     LaTeX is missing and tells Gemini to use Unicode Text() instead of
     MathTex (health endpoint will show  latex:false).
   • For full LaTeX-quality videos: install MiKTeX (miktex.org, includes
     dvisvgm), reopen the terminal, restart the server.
   • Windows Firewall prompt → "Allow on private networks".

───────────────────────────────────────────────────────────────────────────────
STEP 5 — WHAT *NOT* TO DO
───────────────────────────────────────────────────────────────────────────────
✗ DON'T git push with .env — it's git-ignored, keep it that way
  (never  git add -f .env).
✗ DON'T share the API key anywhere else / publish the repo with the key
  embedded before REGENERATING the key at aistudio.google.com.
✗ DON'T expose port 8000 to the internet (no router port-forwarding, no
  public tunnels) — keep it localhost/LAN while testing.
✗ DON'T install pip packages into the system Python on Linux (use the venv
  as shown; Ubuntu blocks system pip anyway — PEP 668).
✗ DON'T run the 1080p (-qh) render on a weak PC or while other modes are
  streaming — 1 render at a time is the sane limit on 8 GB RAM.
✗ DON'T put the WSL project folder under /mnt/c/... for real use — Linux
  file I/O over the Windows mount is ~10x slower (Manim renders crawl).
✗ DON'T panic on a one-off "Gemini API is busy" — free-tier 503s are normal;
  resend after a minute. If it happens every single time, tell me.
